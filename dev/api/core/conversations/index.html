    Conversations API

    Purpose

    engine.conversations: model-led conversations over the database (Conversations), and engine.chat_tools (Chat tools).

    Key Modules

    • packages/nl2sql/src/nl2sql/api/conversations_api.py (ConversationsAPI, internal)
    • packages/nl2sql/src/nl2sql/conversations/ (api.py the turn and its loop, agent.py the [CONVERSATION] block and the step checks, prompts.py, store.py ownership and stored rows)
    • packages/nl2sql/src/nl2sql/conversations/tools.py (the chat-tool runner), report.py (the Markdown report)
    • packages/nl2sql/src/nl2sql/api/chat_tools_api.py (ChatToolsAPI, internal)
    • packages/nl2sql/src/nl2sql/conversations/models.py (Conversation, Turn, ToolStep, ModelStep)

    Public Surface

    Every method takes user_context keyword-only and required. A conversation that is not the caller's is ConversationNotFound; one already running a turn is ConversationBusy. ValueError is raised, before anything runs, for: neither or both of text and choice, a choice with nothing pending or not one of the pending options, an empty message, a conversation at max_turns (CONVERSATION_TOO_LONG), retry with no earlier question.

    Method Row
    start(*, user_context, datasource_id=None, dashboard_id=None) -> Conversation C1
    ask(conversation_id, text=None, *, user_context, choice=None, execute=True, cancellation_token=None) -> Turn C1
    stream(conversation_id, text=None, *, user_context, choice=None, execute=True) -> Iterator[Event] C1
    retry(conversation_id, *, user_context, approvals=()) -> Turn C1
    ask_only(conversation_id, question, *, user_context, choice=None) -> QueryResult C1
    get(conversation_id, *, user_context) -> Conversation C1
    list(*, user_context, limit=20) -> list[ConversationInfo] C1
    delete(conversation_id, *, user_context) -> None (ConversationBusy while a turn runs) C1
    tool(conversation_id, name, args=None, *, user_context) -> Turn C2
    report(conversation_id, *, user_context, turns=None, title=None, include_rows=True) -> str C2
    engine.chat_tools.list() -> list[ChatToolInfo] C2
    • start(dashboard_id=...) needs a dashboard the caller owns (DashboardNotFound otherwise).
    • ask returns the stored Turn: status is that of the last step that did not end ok, else answered; error holds {"code", "message"} when the loop itself ended it (MODEL_STEP_INVALID, or RUN_LIMIT_REACHED for stopped, or the PROVIDER_* code when the model provider refused a step). A cancellation_token that is cancelled ends the turn error with CANCELLED after the step in flight.
    • A timeout is not a cancel. Each ask step runs on its own token, a child of the turn's: a run that exceeds pipeline.timeout_s fails that step with error.code PIPELINE_TIMEOUT, and the loop goes on, so the model can say so in its reply (within max_tool_calls). Cancelling the turn's token still cancels the step in flight. ask_only (MCP's ask) returns the timed-out QueryResult with PIPELINE_TIMEOUT, and a stream stores the turn as usual.
    • stream ends with conversation.turn; see Streaming.
    • ask_only returns the run's QueryResult with its rows; the stored turn has none.
    • tool runs one enabled chat tool as a turn of kind tool and makes no model call. Arguments the tool's args_model rejects are a ValueError and store nothing; a tool that is not enabled, raises or cannot apply is a stored step with error.code UNKNOWN_CHAT_TOOL, TOOL_FAILED or TOOL_NOT_APPLICABLE.
    • report returns Markdown for the stored answered turns (or turns, a list of turn numbers). A turn number that does not exist, or a conversation with nothing answered, is a ValueError. include_rows=False leaves the row tables and chart takeaways out, which is how the report tool stores its output.
    • Every method needs a caller: user_context=None, or a context with no user_id, is a TypeError, not a shared anonymous owner.
    • engine.chat_tools.list() takes no caller: it lists the enabled tools' names.
