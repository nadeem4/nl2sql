# Benchmark Results

Recorded benchmark runs of the engine on the Chinook gold questions. Generated by
`nl2sql benchmark publish` from the records in `benchmarks/`; do not edit by hand.
Grouped by benchmark and database, newest first. "Δ vs previous" is the change against the
previous run of the same config; runs on another gold dataset (`@sha`), another schema or,
for tier 2, other roles are not comparable and start a new series. See
[the evaluation dataset](testing/evaluation-dataset.md).
