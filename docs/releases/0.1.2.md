# NL2SQL 0.1.2

<!-- summary:start -->

A release-pipeline fix: a merged release PR now reaches PyPI on its own. The packages are the same as 0.1.1.

<!-- summary:end -->

*Released 2026-09-07.*

## Highlights

- Merging the release PR publishes all three packages to PyPI with no manual step. On 0.1.1, that upload failed.
- Library code has not changed since 0.1.1.

## What's included

### Fixes

- The release workflow publishes without PEP 740 attestations. Through the called workflow, PyPI rejected them ([#80](https://github.com/nadeem4/nl2sql/pull/80)).

## Known limits

- Released packages have no PEP 740 provenance attestations. That is the cost of this fix.
- The project is pre-1.0, so the API can still change between minor versions.

## Upgrading

```console
pip install --upgrade "nl2sql-engine==0.1.2"
```

Breaking changes: none.
