# NL2SQL 0.1.0

<!-- summary:start -->

The first release: the NL2SQL engine, its REST API and the adapter SDK on PyPI as three packages that share one version.

<!-- summary:end -->

*Released 2026-08-28.*

## Highlights

- `pip install nl2sql-engine` gives you the engine and the `nl2sql` CLI. `nl2sql-api` serves it over REST, and `nl2sql-adapter-sdk` is what a third-party database adapter builds against.
- The model writes a typed plan, never SQL. The plan is checked against the schema and your role before any SQL is generated.
- A DuckDB adapter joins PostgreSQL, MySQL, SQL Server and SQLite.
- The Docker demo now starts the application as well as its databases, so it can answer a question with nothing else installed.

## What's included

### Features

- A DuckDB adapter, installed with the `nl2sql-engine[duckdb]` extra ([#57](https://github.com/nadeem4/nl2sql/pull/57)).
- The Docker demo runs the application next to its databases. SQL Server is now opt-in, so the first start skips a 1.6 GB download ([#59](https://github.com/nadeem4/nl2sql/pull/59)).
- Releases are automated: release-please writes the changelog, and a merged release PR publishes to PyPI ([#58](https://github.com/nadeem4/nl2sql/pull/58)).

### Fixes

- Cancelling one run no longer cancels every other run in the process ([#48](https://github.com/nadeem4/nl2sql/pull/48)).
- The REST API needs its CORS origins listed. It no longer accepts any origin together with credentials ([#49](https://github.com/nadeem4/nl2sql/pull/49)).
- The minimum versions of pydantic, langgraph and chromadb are now correct ([#50](https://github.com/nadeem4/nl2sql/pull/50)).
- Importing `nl2sql` no longer changes your application's logging setup ([#51](https://github.com/nadeem4/nl2sql/pull/51)).
- The `NL2SQL` facade builds its settings API correctly ([#52](https://github.com/nadeem4/nl2sql/pull/52)).

### Docs

- The README and architecture docs now describe only code that exists ([#54](https://github.com/nadeem4/nl2sql/pull/54)), and the docs cover the three-package layout ([#60](https://github.com/nadeem4/nl2sql/pull/60)).

## Known limits

- No API image was published to GHCR for 0.1.0, because the image build failed. 0.1.1 fixes the build.
- The project is pre-1.0, so the API can still change between minor versions.

## Upgrading

```console
pip install "nl2sql-engine==0.1.0"
```

Breaking changes: nine earlier distributions are now three, `nl2sql-engine`, `nl2sql-api` and `nl2sql-adapter-sdk`, and the dialect adapters ship inside the engine ([#56](https://github.com/nadeem4/nl2sql/pull/56)). The import name is still `nl2sql`.
