# NL2SQL 0.2.1

<!-- summary:start -->

A release-pipeline fix for 0.2.0: the API image is built on Python 3.12, and the hosted demo deploys reliably. The library is unchanged.

<!-- summary:end -->

*Released 2026-10-10.*

## Highlights

- `ghcr.io/nadeem4/nl2sql-api` is published again. 0.2.1 is the first image of the 0.2 line.
- The Space deploy waits until PyPI serves the new version, and retries its install.
- A Space deploy only passes when the Space is actually running.

## What's included

### Fixes

- The release image moves to Python 3.12, which every package requires. A new PR check builds the image, so a broken Dockerfile fails before release ([#208](https://github.com/nadeem4/nl2sql/pull/208)).
- The Space deploy waits for PyPI to list the version before it pushes, and the Space's install retries up to ten times ([#208](https://github.com/nadeem4/nl2sql/pull/208)).
- A redeploy that pushes nothing asks for a rebuild, and the job fails unless the Space ends up running ([#208](https://github.com/nadeem4/nl2sql/pull/208)).

## Known limits

- There is no `nl2sql-api:0.2.0` image. Use 0.2.1 or later.
- Without a key, the hosted demo only answers the 20 guided questions it has recordings for.
- A question that needs several sub-queries can be answered wrong without an error. 0.2.2 fixes the known cases.

## Upgrading

```console
pip install --upgrade "nl2sql-engine[demo]==0.2.1"
```

Breaking changes: none.
