# Contributing

The rules a change has to keep, how to set up a checkout and how to run the tests are in
[CONTRIBUTING.md](https://github.com/nadeem4/nl2sql/blob/main/CONTRIBUTING.md) at the repository
root. The short form of the rules is
[CLAUDE.md](https://github.com/nadeem4/nl2sql/blob/main/CLAUDE.md); the reasoning behind each is in
[Invariants](../how-it-works/invariants.md).

- [Testing Architecture](testing.md): the test markers and what each one needs.
- [Real-Database Test Bed](test-bed.md): the Docker Compose test bed and its cloud twin.
- [Releasing](releasing.md): how a release is cut, published and verified.
- [Extending NL2SQL](../extend/index.md): adapters, chunk types, the planner, execution backends.

Report a vulnerability privately; see
[SECURITY.md](https://github.com/nadeem4/nl2sql/blob/main/SECURITY.md). Everyone taking part follows the
[Code of Conduct](https://github.com/nadeem4/nl2sql/blob/main/CODE_OF_CONDUCT.md).
