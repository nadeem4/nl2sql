# NL2SQL Engine

Ask a database questions in English. The model writes a typed query plan, never
SQL text; the plan is checked against the real schema and the caller's role
before any SQL is generated. Every answer shows the plan, the checks it passed,
the SQL and the rows.

| Package | Import | PyPI | What it is |
| --- | --- | --- | --- |
| `packages/sdk` | `nl2sql_sdk` | `nl2sql-sdk` | The interfaces an extension implements. Depends on pydantic only. |
| `packages/nl2sql` | `nl2sql` | `nl2sql-engine` | The facade, the pipeline, the built-in adapters and the MCP server. |

The web app's source is `nl2sql-ui/`. The four packages share one version and
are released together. Other folders: `docs/` (the MkDocs site), `benchmarks/`
(recorded benchmark runs), `examples/`, `deploy/` and `testbed/`.

## Quickstart

Requires Python 3.12 or newer.

```bash
pip install "nl2sql-cli[web]"
nl2sql demo
```

`nl2sql demo` writes a project folder (`./nl2sql-demo`) with three sample
databases, indexes them on your machine, starts the web app on
<http://127.0.0.1:8765/> and opens your browser. With a model key in the
environment (`OPENAI_API_KEY`, `OPENROUTER_API_KEY` or `ANTHROPIC_API_KEY`) it
answers live; without one it replays recorded answers and says so, and you can
paste a key into Settings. The first run downloads a ~79 MB embedding model.
Full guide: [Demo](https://nadeem4.github.io/nl2sql/latest/get-started/demo/).

From a clone: `pip install -e packages/sdk -e packages/nl2sql -e packages/api -e "nl2sql-cli[web]"`.

In Python:

```python
from nl2sql import NL2SQL, UserContext

engine = NL2SQL.demo()                 # the bundled databases
engine.index.build()                   # once
result = engine.run_query("How many customers are there?",
                          user_context=UserContext(roles=["admin"]))
print(result.final_answer["summary"] if result.final_answer else result.errors)
```

The real model end to end on the Chinook suite. Accuracy is execution accuracy, the measure 0.6's tier 2 published: the strict share whose rows match the expected rows exactly, or that are refused where the case expects a refusal (`result_match` and `outcome`; no other scorer counts). ## Contributing, security and license

(`pytest -m "not integration and not realdb"` runs without a database or key).
[`CLAUDE.md`](CLAUDE.md) is the short form of the rules a change has to keep:
package boundaries, no dialect outside an adapter, validation before generation.

the reasoning is in [Invariants](docs/how-it-works/invariants.md).
